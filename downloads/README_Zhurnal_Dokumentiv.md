# Журнал документів 1.0 — учёт на основе Word-журнала

[Скачать программу для Windows 11 x64](./Zhurnal_Dokumentiv_Windows11_v1.0.zip)

Распакуйте ZIP и запустите **Zhurnal_Dokumentiv.exe**. CMD и установка дополнительных компонентов не нужны. «Створити ярлик» создаёт отдельный ярлык «Журнал документів». Прежняя программа «Облік роботи» не заменяется.

## Перенос записей из Word

Нажмите «Імпортувати з Word», выберите свой DOCX и проверьте предварительный список. Затем нажмите «Імпортувати вибране». Документ читается локально через программу на компьютере, без отправки в Интернет. В опубликованном EXE и исходниках нет персональных записей; их выбирает сам пользователь.

Импортируются таблицы журналов: реклисты с четырьмя графами (номер, дата, получатель, примечание) или с отдельной пятой графой СЕДО; планы перемещения с четырьмя графами (дата, ПІБ, СЕДО, примечание). Смешанные значения вида «472 СЕДО 2961» разделяются по полям, исходный номер сохраняется. Считываются текстовые поля Word и оформление фамилий заглавными буквами.

Пустые строки не создают записи. Неполные данные сохраняются как черновики и не увеличивают итоги. Точные повторы предыдущего импорта пропускаются; похожие записи требуют ручного выбора. Одинаковые строки внутри одного исходного документа сохраняются при первом импорте, но не удваиваются при повторном. Для изменённого документа предварительный просмотр обязателен.

## Работа

- Два отдельных журнала, без подписи. В планах нет лишнего порядкового номера, есть СЕДО.
- Добавление и исправление записей; отдельное оформление фамилии заглавными буквами.
- Фильтр по месяцу и диапазону дат, поиск по ПІБ, номеру, СЕДО и примечанию. «Усі дати» показывает все месяцы.
- Дневные и месячные количества: одна активная завершённая запись — один документ. Черновики и корзина не учитываются.
- Удаление в корзину и восстановление. Устаревшее редактирование из другого окна блокируется.
- Экспорт выбранного журнала в CSV, обоих журналов в Word, печать текущей таблицы.
- Резервные JSON-копии с подтверждением восстановления.

## Хранение

Данные находятся в `%APPDATA%\ZhurnalDokumentiv\register.json`; `.bak` содержит предыдущее сохранение. Регулярно сохраняйте независимую резервную копию. Исходный Word не меняется, сканы не копируются. Новое приложение не читает и не удаляет старый индекс «Облік роботи».

Локальный сервис привязан к `127.0.0.1:47833`, запросы к данным защищены ключом текущего запуска и проверкой происхождения. Персональные записи не шифруются в файле: используйте разрешённую рабочую учётную запись Windows. Для выхода нажмите «Завершити програму»; повторный запуск EXE открывает уже работающее окно.

## Проверка

Пройдены тесты XML/DOCX, полей Word, дат, смешанных номеров, повторного импорта, одинаковых строк исходника, редактирования, корзины, сохранения и экспорта. Дополнительно проверен приватный заполненный документ без включения его содержимого в публикацию.

В Chromium пройдены сценарии импорта, CRUD, дат, итогов, СЕДО-поиска, CSV, Word, резервных копий, защиты локальных запросов и настоящего перезапуска процесса. Экспорт Word открыт в LibreOffice и осмотрен визуально. EXE собрана для Windows x64. Реальный запуск EXE и создание ярлыка на Windows здесь не проверены; цифровой подписи нет.
