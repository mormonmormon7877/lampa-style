# Кадровий архів 2.0 — Windows 11 x64

[Скачать приложение без копирования документов](./Kadrovyi_Arkhiv_Windows11_v2.0.zip)

Распакуйте ZIP и запустите `Kadrovyi_Arkhiv.exe`. Выберите папку с оригиналами документов (например, на диске D:). Карточки предлагаются по ФИО в названиях личных папок. Проверьте распределение и добавьте ссылки. Документы остаются на месте и открываются стандартной программой Windows. OCR не выполняется.

В выбранной папке сохраняются `.kadrovyi-index-v2.json` и его предыдущая версия `.bak`: карточки, журнал работы и относительные пути, без содержимого сканов. На C: остаются небольшой файл настроек и обычный кэш браузера. Не переименовывайте и не перемещайте привязанные документы. При переносе всего архива вместе с индексом выберите новое расположение.

Резервная копия карток **не содержит сами документы**. Сканы резервируйте отдельно.

## Переход со старых версий

Сохраните резервную копию, закройте старую вкладку и перезагрузите Windows. Запустите новую EXE в том же браузере и профиле. В разделе перехода доступны перенос карточек/журнала и проверяемая очистка старых копий браузера. Очистка требует совпадения содержимого всех старых документов с оригиналами выбранного архива (SHA-256), сохранения карточек/журнала и подтверждения пользователя. Если оригиналы не найдены или старая база изменилась во время проверки, очистка блокируется. Исходные файлы не удаляются.

## Проверка

Сборка Windows x64 выполнена. Пройдены тесты индекса, ссылок, повторного импорта, сохранности оригиналов, восстановления данных, проверки исходных файлов и очистки старого хранилища в Linux/Chromium. Запуск новой EXE и системный выбор папки Windows здесь не проверены. Цифровой подписи нет. Шифрование не реализовано.

[Исходный код версии 2.0](./Kadrovyi_Arkhiv_v2.0_source.zip). Контрольные суммы архивов: `SHA256SUMS.txt`.

Приложение не связано с плагинами Lampa; их файлы не изменены. Предыдущие версии сохранены для истории и создают копии документов в браузере.
