# Кадровий архів — Windows 11 x64

[Скачать приложение](./Kadrovyi_Arkhiv_Windows11.zip)

1. Скачайте ZIP и выберите «Извлечь всё».
2. Запустите `Kadrovyi_Arkhiv.exe` из распакованной папки.
3. Приложение откроется в браузере по умолчанию. Дополнительные компоненты устанавливать не нужно.

Есть карточки людей, поиск, добавление документов, журнал работы и резервное копирование.
Данные хранятся локально в браузере. Используйте тот же браузер и профиль для повторного открытия; регулярно сохраняйте резервные копии. Старая база PowerShell автоматически не переносится. Начните с вымышленных данных: шифрование хранилища не реализовано.

Сборка Windows x64 выполнена. Интерфейс, сохранение файлов и восстановление резервных копий проверены в Linux/Chromium. Запуск EXE на Windows пока не проверен. Цифровой подписи издателя нет.

Приложение не связано с плагинами Lampa. Файлы плагинов не изменены.
Контрольная сумма ZIP находится в `SHA256SUMS.txt`.
