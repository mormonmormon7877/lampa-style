# Облік роботи 1.4 — папки по полному пути и письменные согласия

[Скачать для Windows 11 x64](./Oblik_Roboty_Windows11_v1.4.zip)

Распакуйте ZIP и запустите **Oblik_Roboty.exe**. CMD, Python и установка дополнительных компонентов не требуются. Перед обновлением сохраните резервную копию индекса и нажмите «Завершити програму» в предыдущей версии; простое закрытие окна может оставить её работающей в фоне.

Внутри программы есть «Створити ярлик»: она копирует EXE в постоянную пользовательскую папку, сохраняет значок и создаёт ярлык на фактическом рабочем столе Windows, включая перенаправление OneDrive. Для этой операции CMD и PowerShell не используются. Исходные документы и индекс не изменяются.

## Добавление папок

Вставьте полный путь из Проводника в «Повний шлях до папки» и нажмите «Додати за шляхом». Можно использовать и прежнее окно выбора. Кириллица, пробелы и окружающие кавычки поддержаны. Известная физическая папка обновляется автоматически без дублей. Для новой папки подтвердите название источника. При восстановлении старого JSON с неподключёнными источниками выберите нужный источник перед подключением его папки.

Ошибочный путь не очищает индекс. Если вложенная папка недоступна, показывается предупреждение и сохраняются прежние признаки доступности документов. Символические ссылки и переходы за пределы выбранного источника не выполняются.

## Документы и отчётность

Три типа: «Рекомендаційний лист», «План переміщення», «Письмова згода». Счётчики, фильтр и CSV учитывают письменные согласия. Поддержаны Word, PDF, RTF, ODT и изображения JPG/JPEG/PNG/WebP/TIFF/BMP. Тип определяется по названиям файлов и папок; OCR не выполняется. Ручные типы и даты выполнения сохраняются при обновлении источника.

Считаются файлы, а не уникальные выполненные работы: Word и PDF одного документа могут быть двумя записями. Для достоверного месячного отчёта задайте дату выполнения и выберите её как основу фильтра. CSV включает все отфильтрованные записи, даже если таблица показывает только первые 1500.

«Відкрити оригінал» передаёт исходный путь стандартной программе Windows. Приложение не копирует документы на C:. Установленная программа для формата и доступ к оригиналу обязательны. Для онлайн-файла OneDrive может потребоваться Интернет. Облачные reparse-теги Windows поддержаны.

## Данные и диагностика

Сохраняется прежний `%APPDATA%\OblikRobotyNative\index.json` и предыдущая версия `.bak`; обновление с 1.3/1.3.1 не удаляет индекс. С браузерных 1.1/1.2 импортируйте резервную JSON-копию и подключите папки. Новые типы и форматы требуют 1.4 или новее. В индексе нет содержимого документов, резервируйте сами сканы отдельно.

При ошибке нажмите «Звіт про помилку»: JSON содержит версию, пути источников, число записей и события, без содержимого документов. Проверьте пути перед передачей отчёта. Ограниченный журнал также сохраняется в `diagnostics.log` рядом с индексом. Программа доступна только локально, на `127.0.0.1:47832`.

## Проверка

Загруженный пользователем EXE точно совпал с опубликованной версией 1.3.1 по SHA-256 (`fb1b42be6b7abfeadd43d6a75e2ae75840cb95128311be78dcc7f58659c7ca6d`). Для 1.4 пройдены 7 Go-тестов и проверка гонок, сборка Windows x64 и браузерные сценарии в Chromium: полный путь с кириллицей/кавычками, фото согласий, повторные папки, сохранение типов/дат, частичный доступ, диагностика, CSV, восстановление связей при настоящем перезапуске процесса. Просмотрен интерфейс новой версии.

В Linux системное открытие имитируется. Реальный Word, OneDrive, диалог Windows и создание ярлыка через COM здесь не запускались. EXE не подписана цифровой подписью; шифрование индекса не реализовано.
