# Облік роботи 1.1 — исправленный индексатор

[Скачать установщик для Windows 11](./Oblik_Roboty_Windows11_v1.1.zip)

Распакуйте ZIP и запустите `USTANOVIT_OBLIK_ROBOTY_1.1.cmd`. Он обновит HTML и создаст ярлык «Облік роботи». Python не требуется.

Исправлены команда создания ярлыка, проверка календарных дат, приоритет имени файла при определении типа и сохранение индекса с ручными исправлениями. Добавлены дата выполнения, резервные копии метаданных, отдельные источники для разных физических папок и отметки пропавших файлов. Поиск, фильтры и CSV сохранены. CSV содержит все отфильтрованные записи, даже если таблица показывает первые 1500.

## Папки на разных дисках

Браузер не раскрывает абсолютный путь папки. Для каждого отдельного архива выберите «Нова папка / інший диск» и задайте уникальную метку, например «D: Архів» и «E: Архів». Для обновления той же папки сначала выберите её существующее джерело. Это позволяет сохранять разные файлы с одинаковыми относительными путями без перезаписи.

## Сохранение и отчётность

В браузере сохраняются только имена, пути, ручные типы и даты; копии документов не создаются. Сохраняйте резервную копию индекса перед очисткой браузера. Для достоверного отчёта задавайте дату выполнения и выбирайте её как основу фильтра. Без неё файлы не попадают в месячный отчёт по дате выполнения. Считаются файлы: Word и PDF одного документа могут быть двумя записями. Содержимое документов не распознаётся.

После перезапуска для просмотра PDF повторно выберите соответствующую папку источника. Word открывайте в исходной папке. Удалённые/перемещённые файлы помечаются при повторном сканировании и исключаются из обычного подсчёта; их исправления остаются в индексе.

## Проверка

В Chromium проверены сохранение после перезагрузки, повторное сканирование, одинаковые пути разных источников, типы документов, ошибочные даты и високосный день, дата выполнения, пропавшие файлы, сохранение/восстановление метаданных, отказ при повреждённой копии, отмена очистки, CSV и 1501 файл. Проверены Base64, SHA-256, CRLF, длины команд, формирование кавычек установщика и ZIP. Сам CMD, ярлык и file://-режим непосредственно на Windows здесь не запускались.
