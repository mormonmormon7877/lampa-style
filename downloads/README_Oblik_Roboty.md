# Облік роботи 1.3 — открытие исходных документов

[Скачать установщик для Windows 11](./Oblik_Roboty_Windows11_v1.3.zip)

Распакуйте ZIP и запустите `USTANOVIT_OBLIK_ROBOTY_1.3.cmd`. Рядом с CMD должны лежать EXE и ICO из архива. Он установит настольный компонент и обновит ярлык «Облік роботи». Python не требуется.

Исправлены команда создания ярлыка, проверка календарных дат, приоритет имени файла при определении типа и сохранение индекса с ручными исправлениями. Добавлены дата выполнения, резервные копии метаданных, отдельные источники для разных физических папок и отметки пропавших файлов. Поиск, фильтры и CSV сохранены. CSV содержит все отфильтрованные записи, даже если таблица показывает первые 1500.

## Папки на разных дисках

Браузер не раскрывает абсолютный путь папки. Для каждого отдельного архива выберите «Нова папка / інший диск» и задайте уникальную метку, например «D: Архів» и «E: Архів». Для обновления той же папки сначала выберите её существующее джерело. Это позволяет сохранять разные файлы с одинаковыми относительными путями без перезаписи.

## Сохранение и отчётность

Сохраняются только имена, пути, ручные типы и даты; копии документов не создаются. В 1.3 индекс находится в локальном файле приложения, в 1.1/1.2 — в браузере. Сохраняйте резервную копию индекса перед очисткой браузера. Для достоверного отчёта задавайте дату выполнения и выбирайте её как основу фильтра. Без неё файлы не попадают в месячный отчёт по дате выполнения. Считаются файлы: Word и PDF одного документа могут быть двумя записями. Содержимое документов не распознаётся.

В версии 1.3 открывайте оригиналы кнопкой в строке документа. В прежней браузерной версии после перезапуска для просмотра PDF требовалось повторно выбирать папку, а Word открывать вручную из исходной папки. Удалённые/перемещённые файлы помечаются при повторном сканировании и исключаются из обычного подсчёта; их исправления остаются в индексе.

## Проверка

Для предыдущей браузерной версии в Chromium проверены сохранение после перезагрузки, повторное сканирование, одинаковые пути разных источников, типы документов, ошибочные даты и високосный день, дата выполнения, пропавшие файлы, сохранение/восстановление метаданных, отказ при повреждённой копии, отмена очистки, CSV и 1501 файл. Проверены Base64, SHA-256, CRLF, длины команд, формирование кавычек установщика и ZIP. Сам CMD, ярлык и file://-режим непосредственно на Windows здесь не запускались.

[Исходники и тесты](./Oblik_Roboty_v1.3_source.zip). Контрольные суммы: `SHA256SUMS.txt`.

## Новый ярлык для уже установленного приложения

[Скачать установщик красивого ярлыка](./Yarlyk_Oblik_Roboty.zip). Распакуйте ZIP и запустите `SOZDAT_YARLYK_OBLIK_ROBOTY.cmd`. Значок: синяя папка с документом и зелёной галочкой. Приложение, сохранённые данные и исходные документы не изменяются. Если Windows показывает прежний значок, нажмите F5 на рабочем столе. Значок сохраняется в папке установленного приложения; существующий выбор браузера в ярлыке сохраняется. Нужна программа, установленная прежним установщиком в `%LOCALAPPDATA%\OblikRoboty`.

Значок ICO содержит размеры 16, 24, 32, 48, 64, 128 и 256 пикселей. Проверены встроенные данные, SHA-256, формат ICO, формирование команды и целостность ZIP. Создание ярлыка непосредственно на Windows здесь не запускалось.

## Открытие оригиналов — версия 1.3

В строке документа нажмите «Відкрити оригінал». DOC/DOCX передаются установленной стандартной программе Windows (обычно Word), PDF — стандартному просмотрщику. Приложение не создаёт копию документа. Путь папки после подключения сохраняется, поэтому повторно выбирать папку при каждом запуске не нужно.

Перед обновлением сохраните «Резервна копія індексу» из прежней браузерной версии. В новой программе нажмите «Відновити індекс», затем для каждого источника выберите его в списке и подключите его исходную папку. Ручные типы и даты сохраняются. Автоматического переноса браузерной базы нет. Установщик оставляет прежний HTML и создаёт ярлык «Облік роботи (попередня)» для экспорта прежнего индекса, если его ещё не сохранили.

В версии 1.3 метаданные и пути сохраняются в `%APPDATA%\OblikRobotyNative\index.json` и предыдущей версии `.bak`, без содержимого документов. Программа работает только локально, на `127.0.0.1:47832`. Чужие источники и незарегистрированные пути открывать нельзя; выход через `..` и ссылки за пределы выбранной папки блокируется. Папка существующего источника не подменяется другой физической папкой без создания отдельного источника.

Проверены передача точного пути системному открывателю, отсутствие копирования, сохранение связей, восстановление прежнего индекса с типами/датами, отсутствующие документы и ограничения путей. Интеграционный тест использует имитацию системного открытия в Linux. Фактический запуск Word, окно выбора папки и установщик на Windows здесь не проверены. EXE не имеет цифровой подписи.
