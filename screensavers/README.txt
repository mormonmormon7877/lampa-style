ПАПКА ЗАСТАВОК LAMPA

1. Загрузите эту папку screensavers целиком в репозиторий lampa-style.
   Она должна находиться рядом с apple-tv-ui-fixed.js, не внутри другой папки.
2. В Lampa: Настройки → Заставка.
   По умолчанию: часы через 2 минуты бездействия после паузы.
3. Выберите «Картинки из папки», «Видео из папки» или смешанный режим.
   Нажмите «Проверить папку» и затем «Предпросмотр».

ДОБАВЛЕНИЕ СВОИХ ФАЙЛОВ
Скопируйте картинки JPG/PNG/WebP/SVG или видео MP4/WebM в эту папку.
Добавьте их имена в manifest.json, например:
{
  "files": ["aurora.svg", "forest.jpg", "ocean.mp4"]
}
Сохраните и загрузите новые файлы вместе с manifest.json на GitHub.
Имена должны точно совпадать, включая большие/маленькие буквы.
Для удобства используйте короткие имена латиницей.

Автоматическое обновление списка на Windows:
Правой кнопкой по Update-List.ps1 → Выполнить с помощью PowerShell.
Скрипт только составляет manifest.json из файлов в этой папке.
Если Windows не разрешает его запуск, просто отредактируйте JSON вручную.

Адрес списка по умолчанию:
https://mormonmormon7877.github.io/lampa-style/screensavers/manifest.json

Часы работают без папки и без интернета.
Картинки сменяются через выбранный интервал. Видео проигрываются до конца,
без звука, затем включается следующий файл. Единственное видео повторяется.
При ошибке файла или недоступной папке остаются часы на чёрном фоне.
Любая кнопка закрывает заставку; для продолжения фильма нажмите Play/OK отдельно.
При действиях с пультом таймер паузы начинается заново.

Для старого Samsung предпочтительнее короткое MP4 H.264 без аудио,
720p или 1080p. Одновременная работа двух видеодекодеров зависит от телевизора:
если видеозаставка не запускается, используйте картинки или часы.
Мод не перематывает фильм, не подменяет его ссылку и не запускает его заново.
